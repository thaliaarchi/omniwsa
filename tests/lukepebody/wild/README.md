# LukePebody Whitespace programs

Whitespace programs written by Luke Pebody for Advent of Code 2022. They were
originally made available [on GitHub](https://archive.softwareheritage.org/browse/origin/directory/?origin_url=https://github.com/LukePebody/AdventOfCode2022.ws),
but the repo has since been taken down and is now [mirrored](https://github.com/wspace/lukepebody-advent-of-code).

I do not include the puzzle inputs which were a part of the repo, because the
creator of Advent of Code [asks](https://adventofcode.com/about#faq_copying)
that they not be redistributed.
